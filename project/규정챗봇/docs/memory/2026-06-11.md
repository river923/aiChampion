### 2. UI/UX 전면 개편
- 하드코딩된 더미 데이터를 걷어내고, Django 서버의 `/api/orgs/tree/` API를 통해 부서 조직도와 캐릭터를 실시간으로 불러와 트리를 그리는 로직 완성.
- **[🔄 새로고침] 버튼** 추가하여 관리자 페이지(서버)에서 변경된 내용이 바로 앱에 반영되도록 함.
- 앱 구동 시 가장 처음 보이는 화면을 "채팅방 내 조그만 폼"에서 **"한국산림복지진흥원 공공기관 스타일의 심플하고 쾌적한 전면 로그인 카드"** 로 완전히 개편.
- 메인 화면 진입 시 로그인 안내 표시(Pill) 제거 및 거슬리는 UI 청소 완료.

### 3. RAG 환각(Hallucination) 억제 시스템 튜닝
- 백엔드(Django)의 답변 근거(Citation) 확인 로직이 텍스트의 정확한 일치만 허용하여 융통성이 떨어지던 버그(환각 아님에도 근거를 날려버림)를 수정.
- 프롬프트에 **"답변 첫 문장에 근거 조항을 명시하라"** 는 지시를 강력하게 부여하여 사용자가 신뢰할 수 있는 형태의 답변을 출력하도록 함.
