## 1. 금일 진행 상황 및 주요 성과

### 1) 오프라인 환경을 위한 로컬 LLM 고도화
- **모델 교체**: 기존 Gemma-2 모델에서, 강과장님께서 발굴하신 모바일 및 엣지 환경에 최적화된 **`unsloth/gemma-4-E2B-it-qat-GGUF`** 양자화 모델로 성공적으로 교체 및 연동을 완료했습니다.
- **성능 확보**: Mac 환경에 맞춘 `llama-cpp-python`과 Metal GPU 100% 가속을 활용하여, 네트워크 단절(오프라인) 상태에서도 초고속 답변이 가능한 아키텍처를 검증했습니다.
- **안정성 개선**: 모델 교체 시 발생하는 메모리 누수 및 재기동 시의 충돌 문제를 막기 위해 백엔드의 구동 방식(Auto-reload 비활성화)을 안정화했습니다.

### 2) 데스크톱 앱 (Electron) 동적 데이터 연동
- 더미 데이터(하드코딩)로 껍데기만 존재하던 UI를 제거하고, Django 백엔드 서버에서 등록된 **최신 조직도와 AI 캐릭터 데이터를 실시간으로 불러와 트리를 구성**하도록 API 통신을 연동했습니다.
- 사용자가 캐릭터를 변경할 때마다 대화의 맥락이 즉시 초기화되는 컨텍스트 스위치 로직을 구현했습니다.

### 3) 공공기관 맞춤형 전면 UI/UX 개편
- 앱 실행 시 **단독 전면 로그인 스크린**이 표시되도록 개편했습니다.
- 신뢰감을 주는 딥블루 포인트 컬러와 중앙 집중형 카드 레이아웃을 도입하여 '한국산림복지진흥원'의 공공기관 모던 디자인 스타일에 부합하도록 디자인했습니다.
- 로그인 성공 후 메인 채팅 화면으로 매끄럽게 전환되도록 처리하고, 채팅창 상단에 위치해 몰입을 방해하던 '백엔드 확인 중' 안내 문구를 완전히 제거했습니다.

### 4) RAG(검색 증강 생성) 답변 품질 개선
- 답변 본문에 근거 조항을 명시적으로 서술하도록 LLM 프롬프트의 지시문을 대폭 강화했습니다.
- 백엔드의 깐깐한 환각 검증 로직(정확한 문자열 매칭)을 유연한 부분 일치 방식으로 개선하여, 우측 '답변 근거' 패널에 문서 및 조항이 누락 없이 정상 노출되도록 버그를 픽스했습니다.
