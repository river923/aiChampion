# [Codex] 채팅 서비스 리팩토링 및 테스트 정상화

**1. 작업 내용 (Content)**
- `backend/test_chat.py`를 `backend/manual_chat_check.py`로, `backend/test_parse.py`를 `backend/manual_audit_log_check.py`로 이름 변경해 pytest 자동 수집에서 제외했다.
- `backend/chat/tests.py`의 조직 fixture를 `OrganizationUnit.objects.create()`에서 treebeard API인 `add_root()`/`add_child()`로 수정했다.
- `.gitignore`를 추가해 `.env`, sqlite DB, `media/`, Python 캐시, `backend/build`, `backend/dist`, GGUF 모델, `node_modules`, Electron `dist`, `.DS_Store`를 제외하도록 했다.
- `backend/chat/services.py`의 책임을 다음 모듈로 분리했다.
  - `backend/chat/types.py`: 답변/인용/LLM 파싱 결과 dataclass
  - `backend/chat/response_parser.py`: LLM JSON 및 markdown fence 제거 파싱
  - `backend/chat/citations.py`: 인용 텍스트 생성 및 느슨한 인용 검증
  - `backend/chat/retrieval.py`: 질문 키워드 추출과 조항 검색
  - `backend/chat/prompts.py`: 프롬프트 및 답변 지침 로딩
  - `backend/chat/audit_writer.py`: 감사 로그 기록
- `backend/chat/test_response_parser.py`, `backend/chat/test_citations.py`를 추가해 파서와 인용 검증 회귀 테스트를 보강했다.

**2. 완성도 (Completion)**
- 1차 리팩토링 목표는 완료했다.
- `backend/chat/services.py`는 266줄에서 74줄로 줄었고, 현재는 답변 생성 흐름 조율 역할만 담당한다.
- 전체 pytest 컬렉션 문제가 해결되어 `backend` 테스트가 정상 실행된다.

**3. 발생한 에러 및 미해결 문제 (Errors & Issues)**

- `desktop/electron-demo`에는 여전히 `npm test` 스크립트가 없다.
- `llm/providers.py`와 Electron 렌더러 분해는 이번 범위에서 수행하지 않았다.

**4. 원래 계획 대비 변경된 사항 (Changes & Workarounds)**
